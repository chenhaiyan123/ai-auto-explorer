
# 🚀 AI 自动探索助手 - 阿里云部署手册

你的 API 代理（阿里云函数）已经就绪。现在只需将前端静态页面托管到 **阿里云 OSS** 即可上线。

## 第一步：本地打包 (Build)

在你的电脑终端（Terminal）进入项目根目录，依次运行以下命令：

```bash
# 1. 安装依赖
npm install

# 2. 编译打包
npm run build
```

完成后，你会看到项目里多了一个 `dist` 文件夹。这就是我们要上传的“全套网页”。

## 第二步：准备阿里云 OSS

1.  登录 [阿里云 OSS 控制台](https://oss.console.aliyun.com/)。
2.  **创建 Bucket**:
    *   **名称**: 自定义（例如 `ai-explorer-web`）。
    *   **地域**: 建议选和你云函数一样的地域（如：华东1 杭州）。
    *   **读写权限**: 必须选择 **“公共读 (Public Read)”**。
3.  **开启静态页面托管**:
    *   进入刚才创建的 Bucket。
    *   左侧菜单选择 **“数据管理” -> “静态页面”**。
    *   点击“设置”，在 **“默认首页”** 填入 `index.html`。
    *   保存。

## 第三步：上传文件

1.  在 OSS Bucket 页面点击左侧 **“文件管理”**。
2.  点击 **“上传文件”**。
3.  **关键点**: 打开你本地的 `dist` 文件夹，将里面的**所有内容**（包括 `assets` 文件夹和 `index.html` 等）拖进去。
4.  等待上传完成。

## 第四步：访问你的助手

1.  上传完成后，回到 OSS 的 **“概览”** 页面。
2.  找到 **“外网访问域名”** 这一栏。
3.  在浏览器访问：`https://你的域名/index.html`。

---

### 💡 进阶建议：绑定域名
如果你有自己的域名，可以在 OSS 的 **“传输管理” -> “域名管理”** 中绑定，并申请免费的 SSL 证书，这样访问地址就会变成 `https://www.yourdomain.com`。

### ⚠️ 安全提示
由于你已经在云函数里处理了 API Key，这个部署在 OSS 上的前端是非常安全的。即使别人爬取你的网页代码，也只能看到指向你云函数的接口地址，而拿不到你的通义千问 API Key。
