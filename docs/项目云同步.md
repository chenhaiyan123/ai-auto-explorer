# 项目云同步

入口：个人中心 → 项目同步。默认关闭，需要邮箱验证码登录。

首次在原浏览器预览并确认同步，然后使用同一邮箱在另一设备预览、确认载入。登录本身不会上传本地项目。项目笔记、总览、团队描述、事实、决策、探索阶段树和对话包含在同步中；设备模型凭据不包含在内。选择自有模型的另一设备需要另行配置 API Key。

开启后，本机编辑防抖 2.5 秒后上传；回到窗口或恢复网络也会检查。另一设备的改动不会突然替换编辑器：个人中心显示待载入提示，用户确认后保存恢复副本并重载页面。没有新改动时仅查询，不写新版本、不调用模型。断网保留本地内容，恢复网络后重试。

## 数据保护

- `/projects/workspace` 只接受后端验证的账号身份，忽略请求体声称的 owner。GET 和 PUT 均需登录。
- 全量快照最多 200 个项目、12 MiB，节点与历史包含在同一快照；代理只对此路径放宽请求体，支付等其他路径仍为 300 KB。
- 三方合并使用每台设备最后同步的内容指纹；不同项目可以合并，同一项目的并发修改、删除与修改冲突必须逐项选择。服务端 revision 比较交换防止陈旧提交覆盖新版本。
- 项目内容和本地基准存在同一个 IndexedDB 记录，按账号分开，持久化事务提交后才重载。保留旧本地项目键用于迁移和恢复，不删除原始数据。
- 云端文件位于既有数据卷 `project-sync/` 子目录，复用后台 AES-256-GCM 密钥，加密保存当前和前一版。单进程写入队列与原子替换；沿用既有后台单副本约束。
- 本地保留最近一次手动同步前的副本，可在同步面板恢复；恢复关闭自动上传，云端不变。不是无限版本备份。管理员可从加密文件的 `previous` 字段恢复上一云端版本。
- 云同步不会启动/暂停研究。现有云端研究仍按项目与分支身份运行；其结果仍通过现有研究面板查看及核验导入。
- 关闭自动上传和清除设备数据不删除云端副本。完整账号及云端数据删除目前需联系支持，尚不满足 App Store 应用内账号删除要求。

## 验证

`npm run wake:build && node --test __test__/project-sync.test.mjs __test__/wake-server.test.mjs`

`npx esbuild __test__/project-sync-client.test.ts --bundle --platform=node --format=esm --outfile=node_modules/.cache/project-sync-test.mjs && node node_modules/.cache/project-sync-test.mjs`

集成测试覆盖登录隔离、伪造 owner、中文大快照、密钥字段过滤、密文存储、重启、并发写入、旧版本拒绝、重复 ID、大小限制和上一版本恢复。客户端验证初次导入、两端新增、分项目修改、删除与修改冲突、本地迁移和账号切换。测试数据均为构造数据，不调用真实模型。

## 上线顺序

先更新后台模块、Dockerfile 与 Caddy 请求限制，验证 HTTPS；然后发布网页，最后更新 iOS 安装包。需要原网页端打开新版并手动首次同步，不能从服务器凭空恢复只存在于浏览器的笔记。
