## 三、验证文件怎么部署（GitHub Pages）

微信会给一个类似 `xxxxxxxx.txt` 的文件，要求放在网站根目录。

1. 把文件放进项目的 **`public/` 目录**（不是项目根目录！）
   —— Vite 只会把 `public/` 里的内容拷进 `dist/` 根目录，你的 `CNAME` 就是这么生效的
2. `git add public/xxxxxxxx.txt && git commit -m "chore: 微信站点验证文件" && git push`
3. 等 Actions 构建完成（1~2 分钟）
4. **用 Safari/Chrome** 访问 `https://www.hiexplore.com/xxxxxxxx.txt`，确认能看到内容
5. 确认能访问后，再回微信点「验证」

> 微信内置浏览器现在打不开这个域名（正被拦截），所以自测必须用外部浏览器。

## 四、如果被驳回

不要反复提交同样的内容，那样只会被降权。按这个顺序排查：

1. **确认部署真的生效了**：用无痕窗口看源码，别被缓存骗
2. **在申诉里直接追问**：要求对方给出检出的具体 URL 和漏洞类型。很多人被驳回是因为没问，一直在瞎改
3. **走公众号渠道**：若有认证服务号，用公众号后台的「网页安全」申诉入口，优先级高于普通入口
4. **考虑迁移到境内主机**：GitHub Pages 是境外 IP。虽然域名已备案，但**备案主体在境内、服务器在境外**这个组合本身就会持续拉低微信的信任分。迁到阿里云 OSS + CDN（与备案接入商一致）通常能根治此类拦截 —— 你备案接入商本来就是阿里云，迁过去还能顺带解决备案接入商与实际接入不一致的隐患。需要的话可以出迁移方案。
