# 接入流量统计（Umami）与用户聊天（Tawk.to）

两个功能都由环境变量开关，不配置就完全不加载，对开源版零影响。代码入口：`services/analytics.ts`（在 `index.tsx` 启动时调用）。

## 一、流量与用户统计：Umami Cloud（免费）

Umami 免费、无 cookie、匿名统计，不用弹 cookie 同意框，国内访问也比 Google Analytics 稳定。

1. 打开 https://cloud.umami.is 注册（免费 Hobby 计划：10 万事件/月，足够）。
2. Add website → 填站点域名（如 `chenhaiyan123.github.io`）。
3. 创建后进入网站设置，复制 **Website ID**（一串 UUID）。
4. 配置：
   - **线上**：GitHub 仓库 → Settings → Secrets and variables → Actions → **Variables** → 新建 `VITE_UMAMI_WEBSITE_ID` = 刚复制的 ID。
   - **本地**：`.env.local` 里加 `VITE_UMAMI_WEBSITE_ID=xxx`。
5. `git push` 触发部署后，打开网站，再回 Umami 仪表盘就能看到：访客数、页面浏览、来源、地区、设备等。

已埋的自定义事件（Umami 仪表盘 Events 页可见）：
- `login` — 用户登录
- `record_decision` — 记录决策（带 trigger 维度）
- `fork_decision` — 从决策点 fork

想加新事件：在代码里调 `trackEvent('事件名', { 维度: 值 })` 即可。

> 自托管 Umami 的话，把脚本地址填到 `VITE_UMAMI_SRC`。

## 二、连接用户：Tawk.to 聊天挂件（免费）

Tawk.to 永久免费，站点右下角出现聊天气泡：用户随时能找你，你在线就实时聊，不在线自动转留言；有手机 App / 网页后台收消息。

1. 打开 https://tawk.to 注册，创建一个 Property（填网站域名）。
2. 进入 Administration → Chat Widget，看到嵌入代码类似：
   `https://embed.tawk.to/<PROPERTY_ID>/<WIDGET_ID>`
3. 配置（同上，GitHub Variables + 本地 .env.local）：
   - `VITE_TAWK_PROPERTY_ID` = PROPERTY_ID
   - `VITE_TAWK_WIDGET_ID` = WIDGET_ID（常见是 `default` 或 `1xxxxxxx`）
4. 部署后网站右下角出现聊天气泡。用户登录后会自动把用户名/邮箱同步给 Tawk（`identifyChatUser`），你能看到在跟谁聊。
5. 手机装 Tawk.to App，用户来消息即时推送。

后台还能看到：当前在线访客、访问页面、地区——也算一份实时用户监督的补充。

## 三、验证

- Umami：部署后访问网站 → Umami 仪表盘 Realtime 里应出现你自己。
- Tawk：右下角出现气泡 → 自己发一条消息 → Tawk 后台/手机 App 收到。
- 都没配置时：浏览器 Network 里不应有 umami/tawk 请求。
