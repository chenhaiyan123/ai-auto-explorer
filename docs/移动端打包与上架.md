# HiExplore iOS 首版

## 当前内容

- Bundle ID：`com.hiexplore.app`；名称 HiExplore；最低 iOS 14（Capacitor 7）。
- iOS 打开完整研究工作区：项目总览、笔记、事实看板、团队对话、个人中心；窄屏使用底部导航与全屏抽屉。
- 本地打包 UI，HTTPS 连接现有验证码、研究与账户服务。云端长期研究不依赖手机进程存活。
- 首次启动说明笔记仍是设备本地存储；没有完整跨设备笔记同步。切勿把“相同邮箱登录”理解为自动恢复网页笔记。
- 原生插件使用字面量动态 import，恢复前台会通知页面刷新。不会在首次启动索要通知权限；重要事件仍用用户主动订阅的邮件。
- 本版无 iOS 应用内购买与成果 ZIP 下载入口；Web 微信支付保持原样。正式上架前按目标地区和产品类型核定 StoreKit 方案，不能把网站二维码支付直接当作 iOS 数字内容购买实现。
- Android 与 PWA 的 `#/m` 现实反馈入口保留。

## 可重复构建

```bash
npm ci --ignore-scripts
npm run ios:prepare
npm run test:ios
```

`ios:prepare` 用独立 `ios` 构建模式，禁止加载 `.env.local`，删除进程继承的所有 `VITE_*`，仅注入三个公开生产 API 地址。生成 `dist-ios`，再同步到原生工程。绝不注入管理员密码、代理地址、开发令牌、API Key。不要用普通 Web 开发构建替换 iOS 发布资源。

原生工程已纳入版本控制；`public/`、生成的配置、构建产物、个人 Xcode 数据与签名凭据不入库。SPM 清单由 Capacitor 同步生成。首次初始化辅助脚本绕过已安装 CLI 7.6.8 的 SPM 参数大小写缺陷，仍使用其原有模板与生成器；没有修改 node_modules。

打开 `ios/App/App.xcodeproj`，选择 App scheme。安装完整 Xcode 与 iOS Simulator 后，可在模拟器运行。真机个人测试可以使用 Xcode 的免费 Personal Team（有签名和使用限制）；TestFlight / App Store 分发需要 Apple Developer Program。

```bash
npm run ios:open
# 或在安装好 Xcode 的机器上验证模拟器编译
xcodebuild -project ios/App/App.xcodeproj -scheme App -configuration Debug \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/hiexplore-ios CODE_SIGNING_ALLOWED=NO build
```

GitHub 工作流 `.github/workflows/ios.yml` 在 iOS 开发分支或手动触发时构建模拟器 App，不需要 Apple 密钥，不部署网站。产物 **只能用于模拟器，不能直接装到 iPhone**。

## 真机与上架验收

1. 登录邮箱验证码、创建问题、模型调用、云端开启/暂停、邮件订阅、前后台切换。
2. 真机键盘、刘海安全区、横竖屏、离线重开、本地笔记保存、退出账号后的数据行为。
3. 原生 HTTP 已启用；必须在真机核验登录及模型请求、超时/取消行为，不能把 Web 测试当作原生网络验收。
4. 上架前完成账户删除、隐私声明及数据收集说明、签名团队、App Store Connect 信息、目标地区资质、当前 SDK 要求和购买方案审查。
5. APNs 尚未配置，不声明推送已可用。不申请 iOS 后台持续执行权限，不承诺手机后台跑模型。
